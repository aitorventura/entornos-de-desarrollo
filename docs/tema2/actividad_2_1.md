# 🧪 Actividad 2.1: Instalación de entornos de desarrollo

## Objetivo

Instalar dos entornos de desarrollo representativos —**IntelliJ IDEA Community** y **VSCodium**— y verificar que funcionan correctamente compilando y ejecutando un programa Java básico en cada uno de ellos.

!!! info "¿Por qué estos dos?"
    IntelliJ IDEA Community es el IDE Java libre más usado en la industria. VSCodium es básicamente VS Code, pero sin el sistema que Microsoft usa para recopilar datos de uso (a eso se le llama telemetría). Mismas funciones, mismo código fuente, pero sin enviar información a Microsoft. Es el editor de código más popular entre desarrolladores según las encuestas anuales de Stack Overflow. Conocer los dos cubre los dos extremos: un IDE especializado en Java frente a un editor ligero que sirve para cualquier lenguaje.

## Lo que vas a necesitar

Instalar en tu máquina (en el orden indicado):

1. **JDK 21 LTS** — el compilador y runtime de Java. Sin él, ningún IDE puede compilar código Java.
2. **IntelliJ IDEA Community Edition** — IDE especializado en Java/Kotlin, gratuito y de código abierto.
3. **VSCodium** — editor de código abierto, multiplataforma y sin telemetría.

!!! tip "JDK: usa Eclipse Temurin"
    Oracle JDK requiere licencia de pago en entornos profesionales. **Eclipse Temurin** es la distribución libre de OpenJDK mantenida por la Adoptium Working Group. Descárgala en [adoptium.net](https://adoptium.net) y elige Java 21 (LTS).
